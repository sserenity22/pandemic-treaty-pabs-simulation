    TRANSPARENCY BY DESIGN

    Know what sits behind each result.

    Every number in this demo is fictional. None is a forecast or an offer to Pakistan.

    ILLUSTRATIVE INPUT

    A design exercise

    The population, delivery dates, coverage curves and costs were created to demonstrate the proposed experience. They do not come from the existing simulation or a validated country model.

    REQUIRES REVIEW

    A future country pilot

    Real use requires sourced observations, an agreed allocation rule, eligibility, available supply, delivery capacity and independent review of the model.

    HOW THE DEMO WORKS

    Clear definitions, visible limits

    Access is conditional

    Global pooled supply does not create an automatic country entitlement. The demo does not establish treaty compliance, legal obligations or political acceptance.

    Local draft storage

    Saving uses this browser’s local storage. No account or server is involved. A downloaded analysis is readable JSON and contains no personal notes.

    What remains to build

    A shared validated calculation engine, documented country data, realistic allocation and delivery models, and specialist review before decision use.
