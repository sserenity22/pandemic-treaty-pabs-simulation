# Illustration provenance

The proposal uses existing project illustrations created for the 21 October 2026 FLUX pitch video. They are illustrative, not documentary, and do not depict an actual WHO event.

- `negotiation-hall.jpg`: resized web copy of `s6b-hall-desks.png`, FLUX 3 Image 1.5k, request `553cd05f-8618-42fe-8c30-c12d0133538d`.
- `pathogen-sharing.jpg`: resized web copy of `s3-cryovial.png`, FLUX 3 Image 1.5k, request `7fd5fd00-2fbd-4409-bebe-e6f54ddbedfc`.

Original assets and generation records are kept with the project's video source files. The existing `app-package.jpg` is a screenshot of the current simulation. The rebuilt page does not use the earlier WHO or Mandela photographs.
