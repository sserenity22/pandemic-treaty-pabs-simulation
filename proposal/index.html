The policy question

Access and benefits form
one negotiating package

01

Rapid scientific access

How can pathogen materials and sequence information move quickly enough to support research and response?

02

Predictable benefit-sharing

How can the system secure enforceable commitments to products, finance and technology?

The tool makes the consequences of different combinations available for discussion.

Positions vary within and across groups. The model tests packages without attributing a delegation’s choices.03 / 12

Whole-package simulation

  2. 02

    Review the consequences

    Examine doses, contributions and modeled support.

  3. 03

    Compare alternatives

    Explore changes across outbreak scenarios.

  4. 04

    Prepare a brief

    Carry the assumptions and trade-offs into discussion.

Scenarios: Ebola-type PHEIC, H1N1-type, COVID-type and a novel pathogen. Some inputs remain placeholders.04 / 12

Trust and delegation control

A private space
to test a position

Exploration carries no negotiating commitment. A delegation decides what to test and what to share.

Local calculations
Package choices are processed in the browser. Saved packages remain on that device.
Voluntary sharing
No account or delegation field in the simulation. Users choose whether to share package codes and notes.
Common assumptions
The same model applies across groups. Priorities and coded positions remain open to correction.
Private text handling
Proposed for the next prototype, subject to agreed hosting terms and security review.
Hosting services may receive connection metadata. Shared notes can identify their author. Private upload is not yet available.07 / 12

Proposed next stage

Today’s text,
in the delegation’s workspace

A narrowly scoped text-reading agent would connect a delegation’s current draft to the existing package model.

  1. 01

    Private source text

    The delegation supplies its own copy of the current draft.

  2. 02

    Cited interpretation

    The agent maps issues and brackets, citing the relevant paragraph.

  3. 03

    Delegation review

    A user confirms the mapping and sees any wording the model cannot cover.

  4. 04

    Package analysis

    The model produces comparisons, suggested alternatives and a brief.

Proposed implementation: the current web model plus an isolated text-agent session for each delegation. Data residency and retention require agreement with the host.

Future capability. Subject to engineering, security review and user testing.08 / 12
